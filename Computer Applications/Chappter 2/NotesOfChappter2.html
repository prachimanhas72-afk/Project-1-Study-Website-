Operating System

Notes

1) Introduction

  • An Operating System (OS) is system software that acts as an interface between the user and computer hardware. It manages the computer's resources and provides a platform for running application programs.

  • The operating system manages CPU, memory, files, input/output devices, and security. Common examples include Windows, Linux, macOS, Android, and iOS.

2) Importance

Operating System is important because it:

  • The operating system controls hardware components such as the CPU, memory, keyboard, mouse, printer, and storage devices. It ensures that hardware resources are used properly.
  • The OS allocates and manages memory for different programs running on the computer. It helps programs run smoothly without interfering with each other.
  • The operating system provides an interface through which users can interact with the computer. Examples include graphical interfaces and command-line interfaces.
  • The OS protects data and computer resources from unauthorized access. It provides features such as passwords, permissions, and user accounts.
  • The operating system provides the environment required to install and run application software. Without an OS, most applications cannot operate effectively.

3) Types Of Operating System

The major types are:

  1. Distributed Operating System
    • It manages multiple connected computers and makes them work together as a single system.
    • It helps share resources and processing tasks between computers.

  2. Network Operating System
    • It manages computers and resources connected through a network.
    • It provides services such as file sharing, printer sharing, and user management.

  3. Real-Time Operating System (RTOS)
    • It processes data and responds to events within a fixed time limit.
    • It is used in systems such as robotics, medical equipment, and industrial control.
